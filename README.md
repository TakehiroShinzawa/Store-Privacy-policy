# Store-Privacy-policy

プライバシーポリシー


**データ収集について**

このアプリケーションは、ユーザーの個人情報を収集、保存、または共有することはありません。


**データのアクセスについて**

このアプリケーションは、パッケージ内に含まれた特定のExcel（`.xlsm`）ファイルを起動します。
アプリケーションは、ユーザーが選択したJSONファイルを読み込み、ユーザーが内容を編集することができます。
編集後、ユーザーが指定した場所に保存を行います。
ファイルの読み取りや編集はユーザーの操作に基づいて行われ、アプリケーション自身が自動的にデータを収集することはありません。


**データの保存について**

ユーザーの設定を保存するためにレジストリに情報を保存し、必要に応じてこれを読み取ることがあります。
編集された情報は、ユーザーが指定した場所にのみ保存されます。
アプリケーションは、ユーザーが明示的に保存操作を行わない限り、データを保存することはありません。


**データのセキュリティについて**

このアプリケーションは、ユーザーのデータを保護するために最善のセキュリティ対策を講じていますが、データの安全性に関して完全な保証はできません。
ユーザーは、自身の責任においてデータのバックアップおよび保護を行ってください。
